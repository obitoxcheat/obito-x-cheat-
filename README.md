# Obito X Archive — GitHub Pages

A responsive static HTML archive page inspired by the supplied screenshots.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Set the source to the `main` branch and `/root`.
5. Save and wait for GitHub Pages to publish.

## Customize
Edit the `clients` array near the bottom of `index.html` to add your own entries, versions, descriptions, and dates.
The page includes working search, category filters, version filtering, sorting, responsive cards, and a details modal.
